# thecorcoran.github.io

Personal portfolio and directory of writing tools and software projects, hosted via GitHub Pages.

## Live Website

Visit the live site: [https://thecorcoran.github.io/](https://thecorcoran.github.io/)

## Project Structure

* **`index.html`** — Main landing page featuring writing tools, project directory, and newsletter signup.
* **`comments.html`** — Dedicated user feedback and comments form.
* **`style.css`** — Shared CSS stylesheet supporting responsive layouts and light/dark theme toggles.

## Features

* **Writing Tools:** Direct access to tools including Adawriter and Morada.
* **Project Directory:** Showcase for projects (Adventure Books, GreatBooks, MiniBook, OnTheFrig) with links to live demos and GitHub repositories.
* **Theme Preference:** Integrated toggle with automatic system preference detection and `localStorage` persistence.
* **Form Handling:** Contact and newsletter submissions powered via Formspree AJAX.
